User CRUD Demo
This is my first demo project uploaded to GitHub while learning and practicing Git & GitHub.
It is a simple User CRUD application built using Java and Spring Boot.

## Tech Stack

- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- Maven
- Git & GitHub

## Features

- Create User
- Get User
- Update User
- Soft Delete User
- MySQL Database Integration
- REST API
- DTO-based Request & Response
- Layered Architecture
